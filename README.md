# GameMonitorWindows

<img src="assets/app-icon.png" width="110" align="right" alt="GameMonitor 图标">

面向 Windows 的游戏时长管理小工具：常驻托盘，按进程关键字识别游戏并记录游玩时长；到达单次时长或每日配额时先提醒、再倒计时，倒计时结束自动关闭游戏进程。

适合希望约束自己游戏时间，或需要帮孩子管理游戏时长的用户。

## 主要功能

### 时长与配额

- 每个监控条目可单独设置 **单次时长**、**每日配额**（0 表示沿用全局总限额）、**间隔期（休息时长）**
- 全局 **每日总限额**：按当天所有条目合计时长计算
- **周末倍数**（0.5~3.0）：周六、周日同时放大单次时长与每日配额
- 临时 **加时 / 减时**（按分钟，可为负）：只对当天生效；本轮加时随会话保存，程序重启后仍然有效

### 提醒与强制关闭

程序内部状态：空闲 → 运行 → 宽限期 → 倒计时 → 间隔期 / 今日已用完

- 到点先进入**宽限期**（默认 5 分钟，可修改），期间可以保存进度后退出
- 宽限期结束进入**倒计时**（默认 60 秒，可修改），倒计时窗口可被取消（需要加时）
- 倒计时结束会**强制关闭**匹配到的游戏进程，并记录结束原因
- 仅窗口标题命中时额外给 10 秒宽限：窗口自己关掉就不结束进程

### 识别方式

- 每个条目可填多个关键字，按顺序匹配、任意命中即视为运行中
- 三种匹配方式：包含 / 精确进程名 / 精确窗口标题
- 支持同名多开与按进程跟踪

### 时段管控

- 可配置多条**允许时段**与**禁止时段**规则，按星期选择生效日
- 支持跨零点规则：后半夜算作规则开始那一天的延续
- 禁止时段：到点立即倒计时并关闭
- 允许时段：照常计时，但不弹窗、不强制关闭

### 悬浮窗

- 桌面悬浮显示当前条目的已用时长 / 剩余时间 / 限额，随状态实时刷新
- 可拖动，支持贴边自动隐藏与鼠标穿透（Ctrl+Alt 切换）
- 文字模板、字体、字号、颜色、背景透明度均可调整；空闲时两段文字往返滚动展示

### 托盘与快捷键

- 托盘菜单显示当前状态摘要和网页控制台地址
- 可暂停监控 / 取消暂停（需管理密码）、打开设置、查看关于、退出程序（需管理密码）
- 支持隐藏托盘图标，改用全局快捷键呼出设置（默认 Ctrl+Alt+G，可修改）
- **开机启动**：写入当前用户启动项，不需要管理员权限
- **防结束守护**：可选择创建每分钟运行一次的计划任务，程序被结束后自动拉起（创建计划任务需要管理员权限）

### 使用记录

- 保留最近 14 天，按天记录：首次开启、末次关闭、已用分钟、启动次数、加时分钟、最后结束原因、是否进入过间隔期
- 提供今日 0~23 时用量柱状图
- 可清空「今天以前」的记录，今日配额不受影响

### 网页控制台（可选）

- 默认关闭；开启前必须先设置管理密码（4~64 个字符）
- 仅本机访问：`http://127.0.0.1:8080`；允许局域网后可用本机局域网 IP 访问，端口可在 1024~65535 间修改
- 可查看状态与今日用量、编辑监控列表与时段规则、加时 / 减时、结束本次、强制关闭、暂停 / 恢复、清空历史
- 端口被占用时启动会明确报错，不会出现「显示已启用但实际没有监听」的情况

### 其他

- 管理密码使用 Windows DPAPI 加密保存在 `config.xml`，不保存明文
- 配置可导出 / 导入为 XML：导出不含管理密码，导入不会覆盖本机密码
- 单实例运行，重复启动会直接退出
- 运行日志按天写入 `%LOCALAPPDATA%\GameMonitor\logs`，单文件过大时自动滚动；可从设置页「关于」直接打开日志目录

## 系统要求

- Windows 10 / 11（x64）
- 发布版为单文件自包含 exe，**无需另外安装 .NET 运行时**
- 程序所在目录需要可写（`config.xml` 与日志生成在 exe 同目录），不建议放在 `Program Files` 下

## 下载与安装

1. 打开 [Releases](https://github.com/mimokini/GameMonitorWindows/releases) 下载最新的 `GameMonitor-<版本>-win-x64.zip`
2. 解压得到 `GameMonitor.exe`，放到一个固定目录（例如 `D:\Tools\GameMonitor`）
3. 双击运行，托盘出现图标即启动成功
4. 升级时直接替换 exe 即可，`config.xml` 与使用记录保持不动

## 快速上手

1. 双击托盘图标打开设置（或按全局快捷键）
2. 在「监控列表」页点「添加」，把游戏进程名（如 `game.exe`）填到关键字里
3. 设置单次时长、每日配额、间隔期，按需调整周末倍数
4. 需要限制每天总时长时，在「常规」页填写每日总限额
5. 需要固定游玩时间窗时，在「时段管控」页添加禁止 / 允许时段
6. 保存后立即生效

## 数据与配置文件

| 内容 | 位置 |
| --- | --- |
| 程序设置、监控列表、时段规则、加密后的管理密码 | exe 同目录的 `config.xml` |
| 使用记录（最近 14 天） | `%LOCALAPPDATA%\GameMonitor\usage-history.xml` |
| 运行日志 | `%LOCALAPPDATA%\GameMonitor\logs\app-yyyyMMdd.log` |

`config.xml` 与使用记录互相独立，配置文件损坏或被删除不会清空历史记录。

## 常见问题

**游戏没有被识别？**
关键字需要与进程名或窗口标题对应。可先切到「包含」匹配，用较短的关键字试；标题命中的情况也可改为「精确窗口名」。

**到时间了为什么没有立刻关闭？**
程序会先走宽限期，再走倒计时，两段时长都可以在设置里修改。

**忘记管理密码了怎么办？**
密码为 DPAPI 加密的本地密文，无法反推。删除 `config.xml` 会清空全部设置（包括密码）与监控列表，需要重新配置；使用记录保存在 `%LOCALAPPDATA%`，不受影响。
